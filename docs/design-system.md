# Design foundations

Approved M0 direction: a quiet educational workbook, with warm paper, dark ink,
forest-green actions, and restrained ochre accents. This is a foundation preview,
not approval of a full homepage or lesson composition.

| Token | Value / usage |
| --- | --- |
| Paper | `#FAF7F0`, page background |
| Surface | `#FFFFFF`, controls and samples |
| Ink | `#202820`, primary text |
| Muted ink | `#526052`, secondary text |
| Primary | `#285943`, actions and focus |
| Accent | `#D3A545`, decorative highlights |
| Error | `#9B3027`, validation text |
| Spacing | 4px base; 8, 12, 16, 24, 32, 48, 64px |
| Radius | 8px controls; 16px panels |
| Focus | 3px solid outline with 3px offset |
| Controls | 44px minimum target goal |

Body text is 18px at a 1.6 line height; headings use a serif system-font stack.
System fonts avoid network dependencies and font licensing changes during M0.
An original locally hosted font selection can be reviewed with the full design.
Color is not the sole indication of validity; errors have text and programmatic
associations. Decorative accents never carry essential text by themselves.

Layouts use fluid widths and content-driven wrapping, with a two-column foundation
layout above 48rem. Browser tests cover desktop and 360px mobile widths, keyboard
focus, 200% root text size, and reduced-motion media preferences. Reduced motion
removes transitions. No timers, streaks, or fabricated learning statistics exist.

The target is WCAG 2.2 AA. Automated axe results and keyboard tests are evidence for
this harness, not certification of the future product. Manual screen-reader work
and full journey checks belong to the later learning interfaces.

The reference site's organization was researched through page text. A rendered
reference audit was blocked by browser tooling; no claims of visual fidelity are
made, and no reference assets or educational materials were copied.
